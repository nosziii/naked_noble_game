# naked_noble_game

**Naked Noble – Sweet Spin** (Modern Organic Premium) teljes képernyős, interaktív promóciós webes játék tabletre és gépre, Docker támogatással.

## Indítás Dockerrel

```bash
docker compose up -d --build
```

Ezután a játék elérhető a böngészőben:
- **URL:** `http://localhost:8080`

## Irányítás
- **Érintőképernyő / Egér:** Kattints a **„✨ PÖRGETÉS →”** gombra (nyerés után pedig a **„KÖVETKEZŐ JÁTÉKOS →”** gombra).
- **Billentyűzet:** Nyomd meg a `Space` vagy `Enter` gombot a pörgetés indításához és a nyereményablak bezárásához.
- **Felső vezérlősáv:** Hang ki-/bekapcsolása, teljes képernyős mód váltása és játékszabály (`?`).
